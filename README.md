# Smart Menu Choice

Create a smart QR-based restaurant menu with two options after scanning the QR code:

Normal Menu – the regular restaurant menu with food items, prices, images and descriptions.

Healthy Menu – a separate menu showing healthier food options with calories, protein, carbs, fats and other nutrition information. It should also indicate which foods are suitable for goals like gym/high-protein, weight management, low-calorie, etc.

The customer should simply scan the QR code and choose between Normal Menu and Healthy Menu, without downloading any app. Keep the design simple, attractive and easy to use.
